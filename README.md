- **⚡ Fast & Responsive**: Modern mobile-first UI with smooth layouts, clean typography, and subtle CSS animations.

- **🎯 Selected Projects Showcase**: Interactive project cards (*Real Estate Project*, *NewsPulse*, and *Autonomous Line-Following Robot*) complete with tech tags and an interactive details modal dialog.

## 🚀 Quick Start & Local Preview

1. **Clone the repository**:
   ```bash
   git clone https://github.com/sajidul11/sajid-portfolio.git
   cd sajid-portfolio
   ```

2. **Open in browser**:
   Simply open `index.html` in any web browser, or serve it using Python:
   ```bash
   python3 -m http.server 8000
   ```
   Then visit `http://localhost:8000` in your web browser.
